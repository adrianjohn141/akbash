# Akbash user guide

This guide describes the hosted Akbash service. It is public documentation, not a source-code or deployment guide.

[Website and dashboard](https://akbash-dashboard.escano.xyz/) · [Contact](https://akbash-dashboard.escano.xyz/contact) · [Repository overview](../README.md)

## Access your workspace

Open the dashboard and sign in with Discord. Select a server you have permission to manage. Available actions depend on your Discord permissions, the server's configuration, and enabled features. If your server is unavailable, check your permissions and contact support for access questions.

## Review moderation activity

Use the server overview and case browser to review moderation activity. Cases provide references for actions such as warnings, timeouts, kicks, and bans. Open the relevant case or evidence view before deciding on further action. Treat member information and captured messages as private moderation material.

## Configure AutoMod

Review the server's automation settings for spam, links, invites, raids, and banned words. Banned-word controls support restrictions to selected channels or the whole server. Check the intended channel scope before saving a rule. Enforcement follows the enabled settings and the bot's permissions.

## Handle appeals, tickets, and reports

Review appeals with the associated moderation context. For tickets and message reports, use the triage view to read the conversation, reply, add staff-only notes, or close the ticket. Confirm the recipient and distinguish a member-facing reply from an internal note before submitting.

## Use the AI assistant

The assistant can answer questions about the selected server's moderation context, including cases, warnings, appeals, and trends. Provider configuration and access controls determine what is available. Review generated answers before making moderation decisions.

The assistant can propose adding a banned word. You must explicitly approve the proposed change, and execution still checks your permissions. Ordinary assistant chat retrieves context without changing moderation settings. See the service's Privacy Policy for information about AI providers and data processing.

## Manage commands and roles

Use the available command controls to enable or disable built-in commands and configure custom commands. Reaction-role tools let authorized staff build role menus. Review the target channels, roles, and permissions before publishing changes.

## Check availability and get help

Open the dashboard to access your workspace. If a specific moderation action fails or the website is unavailable, contact support with the approximate time, affected feature, and a description of the problem.

Use the contact page or akbash@escano.xyz for product support and sensitive requests. Public GitHub issues are for documentation corrections. Never include credentials, tokens, private evidence, or member information in a public issue.

## Privacy and terms

Read the current [Privacy Policy](https://akbash-dashboard.escano.xyz/privacy) and [Terms of Service](https://akbash-dashboard.escano.xyz/terms) before using the service. For privacy requests or security concerns, use the [contact page](https://akbash-dashboard.escano.xyz/contact).
